# Vocal Meterless Above-Note Hierarchy Rule

**Context** - Vocal - Single staff - Melody-only - Meterless - Lyrics
below the staff - No slurs (ties permitted) - Articulations placed above

------------------------------------------------------------------------

## Governing Principle

Engraving order is determined by:

1.  Structural hierarchy
2.  Duration hierarchy (spanners vs note-attached symbols)
3.  Optical clarity (collision avoidance and performer readability)

Clarity overrides rigid taxonomic stacking when conflicts occur.

------------------------------------------------------------------------

# Vertical Stacking Order (Top → Down Toward Notehead)

## 1. Structural Elements

-   Rehearsal marks
-   Tempo indications
-   First/second endings
-   D.C., D.S., al Fine, etc.

## 2. Tuplet Brackets and Numbers

Highest local rhythmic grouping element.

## 3. Range Spanners

-   Hairpins (crescendo / diminuendo)
-   8va lines
-   Trill extension lines

If both hairpin and trill extension are present, hairpin sits above the
trill extension line.

## 4. Note-Attached Fermata

Placed above articulations but below spanners.

## 5. Articulations (Clustered Tightly)

Ordered by visual weight: - Accent - Tenuto - Staccatissimo - Staccato

Articulations form a compact cluster.

## 6. Ornament Glyphs

-   Trill sign ("tr")
-   Mordent
-   Turn

Ornaments sit closer to the note than articulations in strict hierarchy.
In vocal clarity practice, minor optical adjustment is permitted if
needed.

## 7. Tie

Tie is the lowest element above the notehead. No symbol is placed
between tie and notehead.

------------------------------------------------------------------------

# Conflict Resolution Rules

1.  Preserve tie proximity to notehead.
2.  Preserve articulation readability.
3.  Spanners must never collide with articulation clusters.
4.  When vertical compression occurs, shift ornament glyphs before
    altering articulation clarity.
5.  Structural and tuplet elements always remain highest.
